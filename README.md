# 疫苗调拨台

疾控疫苗调拨 Web 应用，覆盖：接种点领用抢占、按效期先到期先出库(FEFO)、冷藏箱限装校验、运输温度超标自动作废并退回库存、签收拒收、处置记录持久化可查。

## 运行

```bash
npm install
npm start
```

浏览器打开 <http://localhost:3000>。

## 业务规则

- **领用即抢占**：接种点提交领用后立即在事务内扣减库存（`BEGIN IMMEDIATE` 串行化并发，先到先得）。库存不足时部分领取，领用单上记录「还差」数量。
- **效期先出(FEFO)**：同一疫苗按效期 `expiry_date` 升序分配批次，先到期的先出库。
- **冷藏箱限装**：调拨出库时校验该冷藏箱「在途已装 + 本单数量」不得超过限装数量，超出则不予放行（409）。
- **温度超标自动作废退回**：运输途中上传温度，疫苗标准为 **2~8℃**；超出范围即判定该批作废，自动生成处置记录并把数量退回可用库存，接种点无法签收。
- **处置可查**：作废记录写入 `disposals` 表，刷新/重开页面后在「处置记录」页签仍可查询。

## 页面

- **库存批次**：入库新增批次、查看可用库存（按效期排列）。
- **领用调拨**：提交领用；「演示：两个接种点同时领用」按钮并发发起两份申请，演示先到先得与短差。
- **冷藏发运**：冷藏箱限装与在途占用；选择领用单与冷藏箱放行；在途发运可上传温度、签收。
- **处置记录**：温度超标作废并退回库存的历史记录。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/sites` `/api/vaccines` `/api/cold-boxes` | 基础数据 |
| GET/POST | `/api/batches` | 批次库存 / 入库 |
| GET/POST | `/api/requisitions` | 领用单 / 提交领用(抢占) |
| POST | `/api/demo/concurrent-claim` | 并发领用演示 |
| GET/POST | `/api/shipments` | 发运单 / 调拨出库(限装校验) |
| POST | `/api/shipments/:id/temperature` | 上传温度(超标自动作废退回) |
| POST | `/api/shipments/:id/sign` | 签收(作废单拒收) |
| GET | `/api/disposals` | 处置记录 |

温度标准可通过 `/api/config` 查看（`tempMin` / `tempMax`）。
